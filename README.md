# strikta.dev

The source of https://strikta.dev, the website of Mightreya AB for Strikta, an AGPL-3.0-only context engine for LLM agents, and its paid add-on Strikta Pro. The site is built with Astro as static pages.

Contract and legal texts on the site are generated from a private source into `content/export/` and are never edited here. Contributions start with an issue: see `AGENTS.md` for the rules that apply to people and coding agents alike.
